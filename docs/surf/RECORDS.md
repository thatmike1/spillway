# Records

P / a clean physical arrival at the wheel records an Open line time, including emergent shortcuts that skip a stage. Full course bests and segment records require ordered Crest, Sluice yard and Outflow passage. Only measured splits are shown. The two categories are independent, so a shortcut cannot replace full-course split records.

F practice and checkpoint respawns invalidate both record categories until R starts a new attempt. R keeps saved bests. A fall after finishing returns near the wheel and preserves the result. Bot and headless runs never write the real profile.

R12 uses user://spillway_r12.cfg, section records_r12. open_best and clean_best are separate fields. The first R12 start can import R11 settings; it never imports or rewrites R11 records. Current flow tests verify separate save/reload and assistance exclusion. Source-stage native result pairs are in outer checkpoints/spillway/r12/open-records/. Those labelled fixtures seed clocks and poses and do not prove a five-second playable route. Final delivered-file persistence remains a gate.
