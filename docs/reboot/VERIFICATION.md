# Spillway verification

The active acceptance contract is ../surf/BRIEF.md. The old reconstruction, folding-city and FEEL suites remain historical developer fixtures. They are not Spillway gates. The default scene uses spillway_main.gd, not the old main/player/world scripts.

Run `./tools/check-spillway.sh` for current behavioral suites. The motor tests cover native CharacterBody3D movement, braking, grace, buffering, look independence, landing continuity, slides, clearance, stair seams and intentional mantle cancellation. The surf tests cover projection acceleration, five earned hops, a90° turn, held surf, wet retention, cap/crease regressions and input replay. Labelled fixture setup may seed pose or velocity; it is separate from normal-spawn route evidence. The positive buffer case releases its tap with autohop disabled, so held jump cannot mask a broken buffer.

`./tools/check-wet-chute.sh --evidence-dir=/absolute/path/outside/git` uses the actual shallow chute with a labelled dry run-up. `--main-pack=/absolute/path/spillway.pck` checks an immutable export. The wrapper requires completion, real water contact, continued slide mode and at least80% wet/dry speed retention. See ../surf/WATER.md for the fixture boundary and source-stage results.

The waypoint and surf drivers inject engine action/mouse events. They never write player pose, velocity, camera or run state. The fast controller reads physical state to choose inputs and is not a human recording. Canonical full-route proof must start at the normal spawn, contain no reset, cross stages in order and finish. A route trace proves one executable line; it cannot establish discovery, comfort or enjoyment.

`python3 tools/analyze-running.py TRACE --output RESULT` measures continuous ordinary locomotion on a completed route. Turns and brief stops stay in the interval. Only executed jumps, slides, surf or mantle interrupt it. Held keys alone do not. Missing results, respawns, nonordered samples or sampling gaps over0.11s invalidate the audit. The report includes the longest stretch, sampled endpoints and uncertainty. A failed or partial route cannot satisfy the no-walk rule.

Access tests place labelled fixtures on the authored course to challenge reachable solids, late crouches, intentional catches, progress admission and supported recovery. They are not full-route proof. Boundary tests drive outward at floor edges and misleading headings, asserting retained support and no respawn. A source-stage geometry sweep also checks smooth fixed valves, reachable ghost solids, banks and rail feet. Geometry changes require native frames as well as collision checks.

Flow tests use the real main, motor and HUD over an isolated collision floor. They seed labelled positions/clocks to test records, practice provenance, ordered splits, physical finish, restart, pause, settings, input focus, projection and persistence isolation. R12 saves use spillway_r12.cfg / records_r12, and no R11 profile writes are allowed. A skipped stage receives no invented split. Flow fixtures are not a substitute for actual arrival routes.

Audio tests establish PCM continuity and actual mixer levels, including wind above16m/s and surf contact/departure. They do not establish listening quality. Native captures name the renderer and hardware. Software rendering on the build host is not Mike's desktop performance benchmark.

`./tools/check-pack.sh /absolute/path/spillway.pck` runs outside the source checkout. It loads every explicit runtime module and shader and checks that scripts can instantiate, then scans engine errors. The export preset must include new modules. A non-null GDScript resource can still have compilation errors; accepting it alone is insufficient. Packaging also checks exact packed startup and includes source/runtime identity and checksums.

`./tools/visual-play.sh FROZEN_PCK FRESH_ABSOLUTE_DIRECTORY` opens an isolated hidden native exploration session. `python3 tools/visual-play.py --inbox DIRECTORY --keys w --seconds .5` sends ordinary controls and returns the next rendered view. Decision replies omit world coordinates; the raw journal keeps them for diagnosis. Actual pause input separates decisions. This is discovery from successive views, not uninterrupted playback. Keep its failures and final state.

`tools/capture-route.gd` loads the configured game, uses the ordinary driver and holds three simulation seconds at the result. Final continuous native movies must use the delivered pack, real input and normal playback speed. Compare encoded frame counts to the original capture. Sparse strips are also useful for approach, airborne and recovery inspection, but do not replace continuous evidence required by the retained reboot contract.

The existing stress runner's R11 matrix and archived RESULTS.md describe historical delivery. R12 needs its own frozen case list, seed/timing/aim parameters, every failure, complete denominator and exact-pack identity. A development source pass during active geometry changes is not canonical acceptance. Current progress and remaining gates are in ../surf/STATUS.md. REPORT.md should describe the delivered build until r12's own gates pass.

For a native actual-route persistence check, append --save-records to tools/capture-route.gd and use a fresh XDG_DATA_HOME exactly at <evidence-dir>/profile. This optional mode enables ordinary finish saving in that isolated profile and verifies the measured elapsed time and splits. Then run tools/check-saved-route.gd headlessly with the same pack/profile and --expected=/absolute/path/record-verification.json in a second engine process. Compare the profile hash before/after reload. It never seeds a run result.
