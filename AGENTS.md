# Working on Spillway

Read START-HERE.md first. It is the entry point for the live architecture, maps, movement, recordings and commands. Do not infer that a file is unused because its name contains an old round number: current code inherits earlier hosts, and stable resource aliases participate in recording identities.

The handover freezes r21 gameplay. Future movement, level or recording work needs an explicit task contract. Preserve F2 physics and original-map behavior unless that contract deliberately changes them. Run `python3 tools/test.py` for current component checks. Before shipping a runtime, geometry, resource-path or record-identity change, run `python3 tools/test.py --slow`: all 48 original-map plays and 288 exact comparisons must pass with zero differences. Fix failures instead of weakening a comparator or replacing its golden data. Read `verification/README.md` for the retained executor/fixture boundary.

Use `tools/play.py`, `tools/test.py` and `tools/export.py` so the official Godot 4.7.2 binary is hash-checked and launches use the shared engine lock. Keep caches, build output, user settings, recordings and generated evidence out of Git. Packed startup verification runs from an empty external directory, so loose source cannot hide a missing resource. Exported verification builds are distinct from immutable published release bytes.

Only original work or third-party assets with recorded redistribution rights belong here. Keep all of these outside the repository, including every historical commit: Mike's own photos and moodboard images; private concept art from `~/.local/state/foldrunner-council/visual/`; Mirror's Edge game files, decompiled code, and the private reverse-engineering `SPEC.md` or its notes from `~/mirrors-edge-re`; secrets, tokens and credentials. Follow asset manifests and provenance. Audit history before the first publication of newly imported material. See `docs/REPOSITORY.md` for this repository's extraction audit and stripped paths.

Keep current architecture/format docs under `docs/`, round briefs/results under `history/rounds/rNN/`, and frozen verification dependencies under `verification/`. Historical test executors observe gameplay; they are not the implementation to edit. `scripts/game.gd`, the named movement/maps/recordings/scoring/UI modules and their live inherited hosts are gameplay.

Release builds go out as GitHub releases on this private repository. Use tag, platform ZIPs and SHA256SUMS; verify downloaded asset hashes after upload. Do not rebuild and silently replace bytes of an existing release. The original `r21` release points to preserved source provenance while its binaries retain their original pre-extraction build identity.
