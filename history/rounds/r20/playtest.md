## Reproduce without the engine

Run from this project directory:

```bash
python3 -I tools/analyze-r20-playtest.py /home/thatmike1/foldrunner-build-2026-11-05/playtest-r19/userdata-spillway/r16_runs --exclude /home/thatmike1/foldrunner-build-2026-11-05/playtest-r18/userdata-spillway/r16_runs --baseline 065f7b27993df7ae2511eb34eb665d271dded13c --output /home/thatmike1/foldrunner-build-2026-11-05/playtest-r19/r20-analysis.json --manifest /home/thatmike1/foldrunner-build-2026-11-05/playtest-r19/r20-input-integrity.json
```

`tools/analyze-r20-playtest.py` imports the actual strict R16 reader and the R19 stop detector. It hashes the whole copied user-data tree and the old recording folder before and after, strict-reads all 90 files, then analyzes only hash-fresh recordings. Cardinality, fresh hash uniqueness, map/preset/rate, direction-award agreement, unchanged input bytes and HOME free space ≥15,000,000,000 bytes are enforced. Source rules are loaded from the specified git baseline and embedded with hashes, so concurrent feature changes cannot silently change the explanation. Outputs must stay outside the input trees.

The evidence includes reference-feet lines every quarter second, the strict reader's top 12 loss sections per run, all low-speed spans, checkpoint events, direction landing/break checks and actual awards, every grapple attach/release/miss with neighboring samples, experiment spatial envelopes and selected exact samples. No engine replay, collision query, native rendering or Windows run was performed. Collider identities/normals, rope forces/release reasons, launch support/used-state, collapse transitions and sensory feedback are unrecorded. Spatial overlap and source-rule consistency are labelled as inference throughout the full report.
