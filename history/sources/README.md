# Historical source snapshots

SOURCES.json one directory above maps each copied source to its original path or command and content SHA256. The prehistory and round folders preserve briefs, result/review records and recorded feedback used by TIMELINE.md. The beads/ files are read-only snapshots collected on 12 November 2026, not current issue state. Their comments remain attributed to their recorded author. git-log.txt preserves the original hashes before repository extraction.

Historical documents retain their original text and relative links. Resolve those links from the origin in SOURCES.json; they are not links to newly staged files. The curated round notes and timeline have their own working links. Source snapshots may discuss private references, but no private reference images, personal photos, original-game material or reverse-engineering specification is copied here.
